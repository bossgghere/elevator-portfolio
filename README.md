# elevator-portfolio

Interactive scroll-driven elevator reveal and clinking cocktail entrance animation landing page, built with React + Vite.

## Features
- **Scroll-driven Elevator Opening**: Dual parting doors gliding left (270°) and right (90°) on scroll.
- **Parallax Rooftop Background**: Smooth 3D depth and scale transformation.
- **Clinking Toast Entrance Animation**: Two hands gliding in with cubic-bezier easing to meet in the center.
- **Web Audio API**: Synthesized penthouse elevator chime and crystal glass toast clink.
- **Responsive & GPU Accelerated**: Ultra-smooth 120 FPS rendering.

## Tech Stack
- React 19
- Vite
- Modern CSS (Custom properties, 3D hardware-accelerated transforms)
- Web Audio API

## Getting Started

```bash
npm install
npm run dev
```
